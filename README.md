# Online Study Platform – Teacher Dashboard

This project is a prototype of a **teacher dashboard for an online learning platform**.  
It is designed to help teachers manage students, courses, and learning materials in a clear and user-friendly interface.

The main goal of this project was to design and implement a modern and intuitive UI for an educational platform.

## Project Status

⚠️ This project is currently **in development**.  
The final version with additional functionality is planned for release in **April 2026**.

## Features

- Teacher dashboard interface
- Course and student management layout
- Navigation between platform sections
- Responsive interface
- Clean and structured UI designed for usability
- Custom UI design created from scratch

## My Role

This is a **personal frontend project** where I worked on:

- UI/UX design
- Frontend development
- Layout and responsive interface implementation
- Interface structure and component logic

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Figma** (UI/UX design)

## Design

The interface design was created by me in **Figma** before implementation.

Design preview is included in this repository.

## Future Improvements

Planned features for the final version:

- Interactive dashboard functionality
- Student progress tracking
- Assignment management
- Improved component structure
- Additional UI improvements
